# ISEMBEA CORPORATION

Responsive bilingual corporate homepage concept for Isembea.

## Included
- `index.html` - single-page corporate homepage
- `css/styles.css` - responsive layout, green/blue/black gradient identity, adaptive light/dark themes
- `js/main.js` - language toggle, theme toggle, mobile navigation, current year
- `sitemap.xml` and `robots.txt` - starter SEO files

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a separate repository named `Isembea-Corporation` under the `Isembea-tech` GitHub account.
2. Upload the contents of this folder to that repository's root.
3. Enable GitHub Pages in repository Settings → Pages.
4. The expected URL is `https://isembea-tech.github.io/Isembea-Corporation/`. If you choose another repository name, update `robots.txt` and `sitemap.xml` to match.
4. Review the page title, description, links, and project status before publishing.

## Notes
- This is a static frontend. No backend or form submission is included.
- The contact action currently links to the Isembea-tech GitHub organization.
- Update project descriptions and status labels as the projects evolve.
- The Isembea OS project link should be checked against the canonical repository/page before public launch.
