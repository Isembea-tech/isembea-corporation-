# ISEMBEA CORPORATION Website

This package is structured for GitHub Pages with **all files in the repository root**.

## Files
- `index.html` - website content
- `styles.css` - responsive visual design
- `main.js` - language, theme, and mobile navigation
- `robots.txt` and `sitemap.xml` - search engine discovery

## Publish with GitHub Pages
1. Upload all files in this folder directly to the root of your repository.
2. Open **Settings → Pages**.
3. Set Source to **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.

The site uses relative asset paths (`styles.css` and `main.js`), so it works from a GitHub Pages project URL.
